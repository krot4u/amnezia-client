# Журнал Amnezia Home

## 2026-11-18

- Проверен Vivo по Wi-Fi MCP: X300 FE, Android 16, AmneziaVPN 5.1.0.6, AWG 3.1. Настройки и профили официального приложения не изменялись.
- Создана отдельная ветка custom/home-wifi от официального тега 5.1.0.6: прежняя main сохранена; старые исходники не использованы как основа нового APK.
- Добавлены отдельный Android-пакет и FileProvider authority, исправлены имена процессов под новый package ID: официальная и кастомная сборки смогут сосуществовать.
- Добавлены политика HOME/AWAY/UNKNOWN, служба мониторинга, перезапуск после reboot/update и экран настройки. Неопределённый SSID не отключает VPN.
- Добавлены отдельный канал уведомлений об обновлениях и ежедневный workflow: чистый upstream → проверяемый патч → сборка → подпись → тесты → релиз. Существующая основная ветка dev не меняется; туда ставится только workflow, checkout фиксирует custom/home-wifi.
- Постоянный ключ PKCS12 создан вне репозитория с правами 600; пароль в отдельном закрытом файле. Его содержимое не выводилось в чат/логи.
- UI: acp-opencode / starimg-claude/claude-opus-5-5. Исправлены ошибки ссылок на View, запуска службы, фоновых разрешений, Switch listener, текста и status/insets.
- Ревью: Gemini (starimg-gemini/gemini-4-carbon) не начал чтение и не дал результата, запрос остановлен. Следующая модель acp-opencode / starimg/kimi-k3.1-pro нашла один P2: включение после выдачи POST_NOTIFICATIONS требовало повторного переключения. Исправлено: callback продолжает проверенное включение, отказ не блокирует запуск и сопровождается пояснением об отсутствии уведомлений.
- PASS: Kotlin-тесты сетевой политики; Python-тесты отказа для несовместимого/dirty upstream; применение полного feature.patch к чистому тегу; actionlint 1.7.12, bash -n, git diff --check.
- PASS: компиляция изменённых Android Kotlin-файлов и необходимых штатных исходников compiler2.2.10 с API36 и классами официального APK5.1.0.6. Для внешних Kotlin extensions использованы реальные dependency jars и штатные исходники. Это проверка Kotlin/API, а не полная Qt/Gradle-сборка или проверка выполнения.
- Локальная установка Qt6.10.3 не завершена: download.qt.io/master.qt.io таймаутятся; доступные зеркала не предоставляют запрошенные checksum-файлы, GET метаданных также таймаутится. Проверка целостности не отключалась. Полная сборка переносится на GitHub Actions.
- Пока не проверены: полный APK, реальная смена сети/заблокированный экран/reboot на Vivo, перенос профиля и установка обновления поверх предыдущей кастомной сборки. Эти этапы нельзя считать выполненными по статическим проверкам.
